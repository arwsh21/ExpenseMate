# ExpenseMate (Budget Buddy) 💰

A clean, reliable personal expense and budget manager built with **Python**, **Streamlit**, and **SQLite**.

---

## 📌 Project Overview
ExpenseMate helps users track income and expenses, set monthly category budgets, monitor financial health, and export/import transaction data.

### Tech Stack
* **Language:** Python 3.12+
* **Frontend / UI:** Streamlit
* **Database:** SQLite3
* **Analytics & Visuals:** Pandas, Matplotlib
* **Testing:** pytest

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/arwsh21/ExpenseMate.git
cd ExpenseMate
```

### 2. Create and activate a virtual environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
# Or run with Streamlit, pandas, matplotlib, pytest
```

### 4. Run the application
```bash
streamlit run app.py
```

### 5. Run test suite
```bash
pytest
```
